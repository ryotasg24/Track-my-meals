## 2. デザインの方針

**ほどよくポップ**（2026-11-07 決定。プレビューで選んだ「P1」）にします。

1. **撮るのがいちばん簡単**：撮影ボタンを、ホームでいちばん大きく、押したくなる形（丸い大きなボタン）にする。
2. **今日の状況がひと目でわかる**：カロリーを太い輪で、栄養素を色の付いたタイルで見せる。残りと超過は、色だけでなく文字（「あと574kcal」「超過」）でも示す。
3. **楽しいけれど、毎日見ても疲れない**：明るいコーラルとクリーム色の背景、丸い形、栄養素ごとの色で楽しさを出す。色を使うのは「押せるもの」「栄養素」「状態」だけにし、文章の部分は落ち着かせる。
4. **iPhoneになじむ**：端末の標準の文字を使い、外部のフォントは読み込まない（基本設計書 7.5の通信先の制限）。数字と見出しは丸みのある文字にする（4章）。

プレビュー画像（作成時に確認したもの）：配色の4案、ポップの2案（P1・P2）、アイコンの2案。

## 3. 色

### 3.1 基本の色
メインの色は**テラコッタ**（2026-11-07 決定）。ポップにするため、明るいコーラル `#E2643F` を塗りに使い、文字・線には濃いテラコッタ `#B8452A` を使います。ライトモードとダークモードは、端末の設定に合わせて自動で切り替えます。

| CSS変数 | 用途 | ライト | ダーク |
|---|---|---|---|
| `--color-bg` | 画面の背景（クリーム色） | `#FFF5EC` | `#1B1411` |
| `--color-surface` | カード、タブの背景 | `#FFFFFF` | `#271E1A` |
| `--color-text` | 本文 | `#3A2418` | `#F7EEE8` |
| `--color-text-sub` | 補足の文字 | `#7A6458` | `#BFAEA4` |
| `--color-border` | 区切り線、入力欄の枠 | `#F1E2D6` | `#3B2E28` |
| `--color-hover` | マウスを乗せたとき | `#FBEDE3` | `#33271F` |
| `--color-primary` | **メインの色（コーラル）**。撮影ボタン・主要ボタンの塗り、カロリーの輪 | `#E2643F` | `#FF8A65` |
| `--color-on-primary` | メインの色の上の文字。**ライトでは20px以上の太字だけに使う**（下の注意） | `#FFFFFF` | `#2A120A` |
| `--color-primary-strong` | 背景の上に置く、メイン系統の文字・線・アイコン・フォーカスの枠 | `#B8452A` | `#FF9D7E` |
| `--color-on-primary-strong` | `--color-primary-strong` の塗りの上の文字 | `#FFFFFF` | `#2A120A` |
| `--color-primary-tint` | 淡いメインの色。おすすめのカード、選択中のタブ、副ボタン、区分のチップの背景 | `#FDE9E0` | `#3A241C` |
| `--color-primary-track` | カロリーの輪の、まだ食べていない部分 | `#F6D9CB` | `#3F2C24` |
| `--color-danger` | 削除などの危険な操作、カロリーの超過 | `#C53030` | `#F28B82` |

**コントラスト比**（2026-11-07 計算）
| 組み合わせ | ライト | ダーク | 判断 |
|---|---|---|---|
| 本文／背景 | 13.51 | 15.89 | ○ |
| 補足の文字／カード | 5.54 | 7.62 | ○ |
| 濃いメインの色の文字／カード | 5.35 | 8.06 | ○ |
| 濃いメインの色の文字／淡いメインの色 | 4.57 | 7.16 | ○ |
| メインの色の上の文字（撮影ボタンなど） | **3.43** | 7.63 | ライトは4.5:1に届かない。**20px以上の太字だけ**に使う（大きな文字の基準3:1は満たす） |
| カロリーの輪（図形）／カード | 3.43 | 7.05 | ○（図形の基準3:1） |
| 危険の色／カード | 5.47 | 6.83 | ○ |

- メインの色の塗りの上に小さな文字（20px未満）を置かないでください。小さな文字が必要な場合は、`--color-primary-tint` の背景に `--color-primary-strong` の文字にします。

### 3.2 栄養素の色
栄養素ごとに色を決め、タイル・グラフ・凡例で同じ色を使います。タイルは「淡い背景＋濃い文字・棒」です。

| 栄養素 | アイコン | 変数（文字・棒） | ライト | ダーク | 変数（タイルの背景） | ライト | ダーク |
|---|---|---|---|---|---|---|---|
| たんぱく質 | `meat` | `--color-nut-protein` | `#2F5FA8` | `#A9C4F2` | `--color-nut-protein-bg` | `#E6EEFB` | `#1F2B40` |
| 脂質 | `droplet` | `--color-nut-fat` | `#9A6100` | `#F0C470` | `--color-nut-fat-bg` | `#FDF0D5` | `#3A2E14` |
| 炭水化物 | `wheat` | `--color-nut-carbs` | `#2F7A44` | `#9AD3A8` | `--color-nut-carbs-bg` | `#E3F3E6` | `#1B3323` |
| 食物繊維 | `leaf` | `--color-nut-fiber` | `#6A47A8` | `#C7B3EE` | `--color-nut-fiber-bg` | `#EFE8FA` | `#2C2340` |
| 食塩相当量 | `salt` | `--color-nut-salt` | `#B42318` | `#F5A39A` | `--color-nut-salt-bg` | `#FDE7E4` | `#3E1E1B` |
| カロリー | `flame` | `--color-primary-strong` | 3.1と同じ | | `--color-primary-tint` | | |

- コントラスト比：タイルの文字／タイルの背景は、ライト4.55〜5.71、ダーク7.53〜8.12。棒・線／カードは、ライト5.14〜6.82、ダーク8.23〜9.97（2026-11-07 計算）。
- 栄養素は、色だけでなく、必ず名前とアイコンを一緒に表示します。

### 3.3 状態の表し方（基本設計書 5.5）
| 状態 | 見た目 |
|---|---|
| 目標まで余裕がある | 通常の表示。「あと◯◯」 |
| 達成（たんぱく質・食物繊維が目標以上） | タイルの右上に、栄養素の色で `check` のアイコンと「達成」 |
| 超過（カロリー・脂質・炭水化物が目標を超えた、食塩が目標以上） | タイルの右上に、栄養素の色で塗った小さな札「超過」（文字はタイルの背景の色）。カロリーの超過は、輪を `--color-danger` にし、「◯◯kcal超過」と表示する |

**おすすめ度の色**（6章 おすすめのカード。2026-11-08 追加）
| おすすめ度 | 変数 | 色 | アイコン |
|---|---|---|---|
| おすすめ | `--color-level-recommend`（-bg） | 炭水化物の緑と同じ | `thumb-up` |
| 食べてOK | `--color-level-ok`（-bg） | たんぱく質の青と同じ | `circle-check` |
| 控えめに | `--color-level-limit`（-bg） | 食塩相当量の赤と同じ | `hand-stop` |

- 栄養素の色の組み合わせをそのまま使うため、文字と背景のコントラストは3.2で確かめた値と同じです。
- 色だけに頼らないよう、「おすすめ」などの見出しとアイコンを必ず付けます。

### 3.4 カレンダーの印（基本設計書 5.5）
色に加えて形を変えて、色の見分けにくい人でも区別できるようにします。

| 状態 | 印 |
|---|---|
| 範囲内（目標の±10%） | `--color-primary-strong` の塗りつぶした丸 |
| 不足（90%未満） | `--color-text-sub` の白抜きの丸 |
| 超過（110%を超える） | `--color-danger` の小さな三角 |
| 今日 | 日付の数字を太字にし、`--color-primary-strong` の枠で囲む |

カレンダーの下に、印の凡例を必ず表示します。

## 4. 文字

| 用途 | 大きさ | 太さ | 文字の種類 | 例 |
|---|---|---|---|---|
| 大きな数字 | 32px（等幅数字） | 800 | 丸み | 今日の摂取カロリー「1,250」 |
| 撮影ボタン | 20px | 800 | 丸み | 「撮って記録」 |
| 画面の見出し | 22px | 800 | 丸み | 「今日の状況」 |
| 栄養素の値 | 18px（等幅数字） | 800 | 丸み | 「38 / 112g」 |
| 小見出し | 16px | 700 | 丸み | 「次の食事のおすすめ」 |
| 本文・ボタン | 16px | 400／600 | 標準 | |
| 補足・凡例・タブの名前 | 12〜13px | 400／600 | 標準 | 「AIによる推定値です」 |

- **丸み**：`ui-rounded, 'Hiragino Maru Gothic ProN', 'Hiragino Sans', 'Yu Gothic UI', 'Meiryo', sans-serif`
  - 数字と英字は `ui-rounded`（iPhoneでは「SF Pro Rounded」）、日本語は「ヒラギノ丸ゴ ProN」で表示されます。どちらも端末に入っている文字なので、外部から読み込みません。
  - ヒラギノ丸ゴ ProN は太さが1種類（W4）だけのため、太字は端末が擬似的に太くします。実装後にiPhone実機で読みやすさを確かめます（★要確認：11章 No.6）。読みにくい場合は、日本語の見出しを標準の文字に戻します。
- **標準**：`-apple-system, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Yu Gothic UI', 'Meiryo', sans-serif`
- PC（Windows）では、丸みの文字が入っていないため、標準の文字で表示されます（開発中の確認用なので許容します）。
- 数字が変わるところは、桁がずれないよう等幅数字（`font-variant-numeric: tabular-nums`）にします。
- **入力欄の文字は16px以上**にします（iPhoneで入力時に画面が拡大されないように）。
- 行の高さは1.6（見出しと大きな数字は1.2）とします。
- 文字の大きさは `rem` で指定し、端末の文字サイズの設定に合わせて大きくなるようにします。

## 5. 余白・角丸・影

| 項目 | ルール |
|---|---|
| 余白 | 4の倍数（4・8・12・16・20・24・32px）だけを使う |
| 画面の端の余白 | コンパクト：16px、ワイド：24px |
| カードの間隔 | 12px |
| 角丸 | カード：24px、栄養素のタイル：16px、食事の写真：14px、入力欄：14px、ボタン・チップ・タブの選択中の帯：999px（両端が丸い形） |
| 影 | ライトのカード：ごく薄い影 `0 2px 0 rgb(58 36 24 / 5%)`。撮影ボタン：下に4pxの `--color-primary-strong` の影（押せる「厚み」を出す）。ダークでは影を使わず、背景色の違いで区別する |
| 押せる部分の大きさ | 44px四方以上（F-RESP-05）。撮影ボタンは高さ64px、主要ボタンは高さ52px |

押せる部品は、押したときに少し縮めます（10.1）。キーボード操作のときは、`--color-primary-strong` の2pxのフォーカスの枠を、部品から2px離して表示します。

## 10. 動き・アクセシビリティ

### 10.1 動き
「心地よいWeb遷移アニメーションの基本ルール6個」（https://photoshopvip.net/152964 ）に沿って決めます。training-appと同じルールに、ポップさを出す小さな動きを加えます。

| ルール | このアプリでの使い方 |
|---|---|
| フェード | 画面の切り替えは、すべて動きとフェード（不透明度0→100%）を組み合わせる |
| 拡大 | 手前の層として現れる画面（記録の追加・読み取り結果）は、96%→100%に拡大しながら現れる |
| 一貫した方向 | 階層の移動は横方向だけ（進む＝右から、戻る＝左から）。タブも並びの向きに合わせて横に動かす。縦の動きは「手前の層」の画面だけに使う |
| 速さ | 画面の切り替えは200〜320ms、ページ内の動き（ボタン・チップ・タブの帯）は150〜200ms |
| 段階的な表示 | 画面の中のカードと栄養素のタイルは、上から順に40msずつ遅らせて表示する（最大200ms） |
| 空間 | 詳しい画面は「右の奥」、戻る先は「左」、記録の追加・読み取り結果は「下から重なる層」 |

**画面遷移の種類**（`src/features/navigation.ts` で決める。単体テストを書く）
| 種類 | 使う場面 | 動き | 時間 |
|---|---|---|---|
| 進む（push） | 食事の詳細、目標、よく食べるもの、体重、日ごとの状況 | 右から40px＋フェード | 280ms |
| 戻る（pop） | 「戻る」 | 左から40px＋フェード | 280ms |
| タブ | 下部のタブ・左のメニュー | 並びの向きに16px＋フェード | 240ms |
| シート | 記録の追加、読み取り結果、ふりかえり | 下から32px、96%→100%＋フェード | 320ms |
| フェード | 置き換え（読み取り中→読み取り結果など） | フェードのみ | 200ms |

**ポップさを出す動き**
| 動き | 内容 | 時間 |
|---|---|---|
| 撮影ボタンを押す | 2px沈み、下の厚みの影が2pxに減る（押し込んだ感触） | 120ms |
| そのほかの部品を押す | 少し縮める（ボタン97%、チップ95%、タブのアイコン90%） | 150ms |
| カロリーの輪・栄養素の棒 | 画面を開いたときと記録が増えたときに、前の値から新しい値まで伸びる | 500ms |
| 「超過」「達成」の札 | 現れるときに、80%→105%→100%と少し弾む | 240ms |
| 読み取り中 | どんぶりのアイコンが、ゆっくり上下に4px揺れる（くり返し） | 1周1,200ms |
| 保存のトースト | 下から8px＋フェード | 200ms |

- 動きの曲線は、すばやく動き出してゆっくり止まる `cubic-bezier(0.22, 1, 0.36, 1)` に統一します。弾む動きだけは `cubic-bezier(0.34, 1.56, 0.64, 1)` を使います。
- 出ていく画面は動かさず、入ってくる画面だけを動かします。
- 端末の「視差効果を減らす」がオンのとき（`prefers-reduced-motion`）は、動きをなくします（読み取り中の揺れも止め、文字だけで知らせます）。

### 10.2 アクセシビリティ
- コントラスト比は、本文で4.5:1以上、大きな文字とアイコン・図形で3:1以上にします（3.1、3.2で計算済み）。
- 色だけで状態を伝えず、文字（「超過」「達成」「あと◯◯」）・アイコン・形（カレンダーの印）を合わせて使います。
- カロリーの輪と栄養素のタイルには、画面読み上げ用の説明を付けます（例：「カロリー：1,250キロカロリー、目標1,824、あと574」「食塩相当量：7.8グラム、目標7.5グラム未満、超過」）。
- 食事の写真には、品目名を読み上げ用の説明として付けます（例：「昼食の写真：味噌煮込みうどん ほか2品」）。
- 端末の文字サイズの設定を大きくしても、表示が崩れないようにします（文字の大きさは `rem` で指定）。
